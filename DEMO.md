1. Equipment and Environment
Required equipment
- A Mac, Windows PC, or Linux computer.
- Python 3.11 installed.
- An internet connection for the initial repository clone and dependency installation only.
- Git installed.
- A terminal application.
- A code editor such as Visual Studio Code (optional).
Software and dependencies
- Python 3.11
- pip
- cryptography
- pytest
The application is intended to run locally. The demo does not require a virtual machine, a server, a cloud account, a network service, or real website accounts. Use only synthetic test credentials during demonstrations.
Network setup
No special network configuration is required. After dependencies have been installed, the manager and encryption demonstrations run locally. Do not use real personal passwords or credentials during testing.

Steps for Demo

1. open terminal
2. change directory to "PasswordManager"
3. run main.py file
4. create a master password and confirm it
5. open JSON file to witness change to it
6. add a password and view change to JSON
7. view saved passwords to confirm
8. view specific password to show hidden information
9. select update password to view change to JSON
10. delete password to view change to JSON
11. exit program and reload 
12. enter master password previously created to enter vault
13. view that everything is still saved

To reset simply delete the JSON file and create a new vault
